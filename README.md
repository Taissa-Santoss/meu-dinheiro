# APP Meu Dinheiro
# Nome: Taíssa Vitória Vieira dos Santos - 843597

## Objetivo do aplicativo

O APP Meu Dinheiro ajuda a pessoa a acompanhar suas finanças do mês, mostrando quanto recebeu, quanto gastou, quanto tem disponível e em quais categorias o dinheiro foi usado.

O app tem duas telas:

- Tela 1 – Visão geral: saldo disponível, total que entrou, total que saiu e uma prévia dos três primeiros gastos do mês. O botão "Ver gastos" abre a Tela 2.
- Tela 2 – Gastos: mês de referência, cada categoria de gasto com valor e barra de percentual sobre o total e o total gasto.

## Como rodar localmente
Pré-requisitos

- Android Studio: Versão usada no desenvolvimento:Android Studio Quail 3 | 2026.1.3 (Build #AI-261.26222.65.2613.15948027)
- Android SDK Platform 37.
- O emulador foi testado em: Pixel 7 (Device Manager do Android Studio), API 33 ou superior


### Passo a passo
1. Clone o repositório: https://github.com/Taissa-Santoss/meu-dinheiro.git
2. No Android Studio: File > Open e selecione a pasta clonada.
3. Aguarde o Gradle Sync terminar sem erros. Se pedir para instalar o SDK Platform 37 ou outro componente aceite.
4. Crie ou selecione um emulador em Device Manager (API 24 ou superior).
5. Com a configuração app selecionada, clique em **Run**.
